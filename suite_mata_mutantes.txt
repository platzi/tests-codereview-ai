NOTA: MUTANTE EQUIVALENTE (no se puede matar, no requiere test)
------------------------------------------------------------------------

 - amounts.py:59, columna 22 - mutacion BitOr -> BitXor / BitAnd
   Linea real: "def parse_amount(raw: str | int | Decimal) -> Decimal:"
   El "|" mutado esta dentro de una anotacion de tipo, no en codigo que se
   ejecute en runtime. Python no evalua las anotaciones como expresiones
   booleanas salvo introspeccion explicita (que este codigo no hace), asi
   que el comportamiento del programa es identico con "|", "^" o "&" ahi.
   Ningun test puede distinguirlo porque no hay diferencia observable de
   comportamiento. Se deja como SURVIVED de forma permanente y esperada.
